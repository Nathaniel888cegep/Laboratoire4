Le programme à pour but de créer un menu de création de personnage.
Dans démarrer le programme, il faut l'ouvrir dans Visual Studio Code et Python doit avoir été préinstaller.
La console va être utiliser pour avoir accèes au menu. Les entrées sont lors du choix du personnage, lors du choix du sexe
, lors du choix de l'arme et lors du choix de la difficulté. Les sorties sont les prints à la fin du menu avec le 
récapitulatif du personnage que l'utilisateur à créer.
